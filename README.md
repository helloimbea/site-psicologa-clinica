# Site – Beatriz Santos | Psicologia Clínica

Landing page de uma psicóloga clínica, feita como trabalho da disciplina de **Front-end** da faculdade.

O site foi desenvolvido apenas com **HTML e CSS**, sem JavaScript.

## Requisitos do trabalho

- [x] Tema de um negócio/serviço real (consultório de psicologia clínica)
- [x] Página organizada em **5 seções (faixas)**:
  1. **Sobre a empresa/profissional**: apresentação e missão
  2. **Produtos e serviços**: áreas de atuação e tipos de atendimento
  3. **Vantagens e benefícios**: por que escolher o consultório
  4. **Outras informações essenciais**: como funciona a terapia e depoimentos
  5. **Contato**: chamada para ação com **formulário no final da página**
- [x] Menu de navegação levando a cada seção
- [x] Layout responsivo (funciona no computador e no celular)
- [x] Rodapé com informações de contato e mapa do site

## Tecnologias

- HTML5 semântico (`header`, `nav`, `main`, `section`, `footer`)
- CSS3 com Flexbox e media queries
- Menu hambúrguer para celular feito só com CSS (checkbox)
- Google Fonts

## Estrutura

```
├── index.html   # página principal
├── style.css    # estilos
└── img/         # imagens do site
```

## Como abrir

Basta baixar o repositório e abrir o arquivo `index.html` no navegador.
